# Озвучка STFR

Озвучка настраивается в [voice_config.json](voice_config.json). Сейчас включены
два языка: `ru` и `en`. Для каждого языка задаются голос Edge TTS, скорость,
желаемый pitch и список локалей Minecraft. Общие эффекты соответствуют варианту
`broadcast`.

## Общая генерация игровых реплик

Из корня проекта:

```bash
bash scripts/generate_voices.sh
```

Проверяется весь датасет обоих языков: тексты, произношение в `speech_segments`,
настройки голоса и эффекты. Генерируются только отсутствующие и изменённые
записи; актуальные OGG переиспользуются. Списки реплик вручную вести не нужно.
Скрипт передаёт параметры общему `build_voice_assets.py`, например `--lang ru`
или `--force`.

## Быстрый предпросмотр

Из каталога `voicelines`:

```text
python preview_voice.py --name broadcast
python preview_voice.py --lang ru --name ru_test
python preview_voice.py --lang en --rate=-10% --pitch=-16Hz --name en_test
python preview_voice.py --show-settings
```

Результат появляется в `output/<язык>/test.reactor_ready.<имя>.ogg` и не меняет
ресурсы мода. Исходная речь кешируется в `raw/`: изменение pitch или эффектов
не требует повторного обращения к Edge TTS. `--refresh` принудительно обновляет
кеш.

Состояние игровых OGG хранится в `build_state.json`. Для каждой записи там
записан хеш текста, языка, голоса, скорости, pitch и эффектов. Обычный повторный
запуск после ошибки генерирует только отсутствующие или устаревшие записи и
сохраняет manifest после каждого успешного файла. `--force` нужен только для
намеренной полной пересборки независимо от manifest.

## Параметры языка

В `languages` каждый ключ является коротким кодом языка для каталога звуков:

```json
"ru": {
  "minecraft_locales": ["ru_ru"],
  "voice": "ru-RU-DmitryNeural",
  "rate": "-5%",
  "pitch": "-20Hz",
  "edge_pitch": "-8Hz"
}
```

- `minecraft_locales` выбирает эту запись для соответствующего языка клиента.
- `voice` — имя голоса Edge TTS.
- `rate` — скорость речи: отрицательное значение медленнее.
- `pitch` — итоговая высота голоса. Дополнительное понижение выполняется
  локально FFmpeg с сохранением темпа.
- `edge_pitch` — безопасное значение, передаваемое Edge TTS. Для Дмитрия
  оставлено `-8Hz`, поскольку при `-12Hz` и ниже сервис иногда не возвращает
  звук.

Если локаль клиента не найдена, используется `default_language`. Если для
конкретной фразы нет записи выбранного языка, игра также берёт доступный язык
по умолчанию.

## Эффекты

- `input_gain_db` — входной уровень голоса перед разделением на чистый и
  обработанный слои.
- `gain_db` — итоговый уровень после сведения слоёв.
- `reverb_room_size`, `reverb_width`, `reverb_damping` — характер отражений.
- `delay_interval`, `delay_feedback` — интервал и затухание короткого эха.
- `wet_mix` — громкость обработанного слоя: `0` почти сухой голос, `1` наиболее
  заметный эффект.
- `pre_delay_ms`, `after_delay_ms` — тишина до речи и запас под хвост эффектов.

Любой параметр можно временно переопределить в предпросмотре, например:

```text
python preview_voice.py --lang ru --input-gain-db=5 --wet-mix=0.5 --after-delay-ms=1800 --name softer
```

## Добавление языка

Например, чтобы добавить китайский:

1. Добавьте объект `zh` в `languages` файла `voice_config.json` и перечислите
   нужные локали Minecraft, например `zh_cn`.
2. Добавьте поле `zh` к нужным фразам в `voicelines.json`.
3. Проверьте одну фразу: `python preview_voice.py --lang zh --name zh_test`.
4. Запустите сборку игровых ресурсов из корня проекта.

```text
voicelines/.venv/bin/python scripts/build_voice_assets.py --force
```

Генератор сам создаст каталог `sounds/voice/zh`, записи в `sounds.json`,
`voice_lines.json` и `voice_languages.json`. Фразы без перевода `zh` будут
пропущены, а в игре для них сработает язык по умолчанию.

## Команды сборки

```text
# Сгенерировать только отсутствующие записи
voicelines/.venv/bin/python scripts/build_voice_assets.py

# Пересоздать все записи после изменения голоса, скорости или эффектов
voicelines/.venv/bin/python scripts/build_voice_assets.py --force

# Пересоздать одну фразу
voicelines/.venv/bin/python scripts/build_voice_assets.py --force --line reactor.start.abort_manual

# Пересоздать записи одного языка без одновременной записи общих каталогов
voicelines/.venv/bin/python scripts/build_voice_assets.py --force --lang ru --recordings-only

# Обновить JSON-каталоги по уже существующим OGG без обращения к Edge TTS
voicelines/.venv/bin/python scripts/build_voice_assets.py --catalog-only

# Удалить OGG языков и фраз, которых больше нет в конфиге
voicelines/.venv/bin/python scripts/build_voice_assets.py --catalog-only --prune
```

Нужны Python 3, FFmpeg с фильтром `rubberband`, интернет и зависимости из
`requirements.txt`. Новая голосовая реплика в игре обрывает предыдущую; штатный
звук уведомления проигрывается отдельно.

## Паузы внутри реплики

Для точной паузы задайте у фразы `speech_segments` с отдельным списком для
каждого языка. Строки синтезируются как речь, целые числа задают миллисекунды
паузы. Пример завершения запуска:

```json
"speech_segments": {
  "en": ["Stabilizers Thermonuclear Fusion Reactor is now", 900, "online."]
}
```

Сегменты кешируются отдельно, краевая тишина обрезается перед склейкой,
общие эффекты накладываются на собранную реплику. Параметры сегментов входят
в хеш сборки. Обычные поля `ru`/`en` остаются полным текстом для каталога.
Ключ `--line` можно повторять, чтобы пересобрать несколько выбранных реплик.

Текущая версия Edge TTS закреплена в `requirements.txt` на 7.3.1; версия 7.2.8
не поддерживает обновлённый протокол сервиса и возвращает HTTP 403.

Для отдельных реплик можно задать `voice_overrides` по языкам с полями
`rate`, `pitch`, `edge_pitch`. Это используется для русских фраз запуска,
на которых Дмитрий иногда не возвращает аудио при отрицательных параметрах
Edge. Нейтральные `rate: +0%`, `edge_pitch: +0Hz` не меняют выбранный голос;
локальный FFmpeg по-прежнему понижает его до заданного `pitch: -20Hz`.

## Русское ударение «ядра́»

В русских репликах с формой «ядра» задано отдельное произношение через
`speech_segments.ru`: `ядраа`. Этот вариант выбран после прослушивания тестов;
знак ударения и выделение гласной не дали нужного результата.
Обычные поля `ru` сохраняют грамотное написание для экранного каталога.
Существующие паузы в `speech_segments` при коррекции сохраняются.
Изменение сегментов обновляет fingerprint: следующий запуск генератора
пересоздаст затронутые записи без необходимости использовать `--force`.
